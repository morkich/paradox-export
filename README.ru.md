# paradox-export

Экспорт таблиц **Borland Paradox** (`.DB`) в **CSV**, **XLSX** или **XML** —
через минимальный графический интерфейс или из командной строки. Работает без
ODBC, BDE и драйверов Borland: формат файла читается напрямую на чистом Python.

Создано для баз Delphi/BDE-приложений (стоматологии, медицинские карты, конторское
ПО 2000–2010-х), которое больше не запускается на современных Windows.

[English README](README.md)

## Возможности

- Читает таблицы `.DB` напрямую: заголовок, кодовые страницы (CP866 / CP1251 /
  CP1252), даты, числа, деньги, логические поля, время, memo.
- Не требует установки ODBC/BDE, работает на 64-бит Windows.
- Обходит всю цепочку блоков данных вместо доверия счётчику записей в
  заголовке (во многих реальных файлах он занижен).
- Три формата вывода:
  - **CSV** — UTF-8 с BOM, разделитель `;` (корректно открывается в Excel);
  - **XLSX** — одна книга, один лист на таблицу, типизированные колонки
    (настоящие даты/время/числа), закреплённая шапка и автофильтр;
  - **XML** — один файл на таблицу.
- Поиск дублей по ключу: строки помечаются колонкой `_dup_key` либо
  остаётся только последняя копия каждой записи (`--unique`).
- Минимальный интерфейс: выберите папку, таблицы, формат — и экспортируйте.

## Требования

- Python **3.9+** (tkinter входит в стандартный установщик Python)
- [`openpyxl`](https://pypi.org/project/openpyxl/) — только для вывода в XLSX

## Установка

```bash
git clone https://github.com/CHANGE_ME/paradox-export.git
cd paradox-export
pip install .            # или: pip install -e ".[xlsx]"  (с openpyxl)
```

Без установки — прямо из исходников:

```bash
python -m paradox_export                 # GUI  (нужен PYTHONPATH=см. ниже)
PYTHONPATH=src python -m paradox_export data out --fmt csv
```

В Windows можно дважды кликнуть `start_export.bat` — он сам прописывает
`PYTHONPATH` и открывает интерфейс.

## Использование

### Интерфейс

```bash
paradox-export-gui
```

1. Укажите папку с файлами `.DB` (таблицы подхватятся автоматически);
2. отметьте таблицы (или оставьте «выбрать все»);
3. выберите формат и папку назначения;
4. нажмите **Экспорт**.

### Командная строка

```bash
# все таблицы из data/ -> CSV
paradox-export data out --fmt csv

# одна таблица, только уникальные ключи, XLSX
paradox-export data out --fmt xlsx --unique PATIENT

# несколько таблиц в XML
paradox-export data out --fmt xml PATIENT RECEPT
```

| Опция | Значение |
|-------|----------|
| `--fmt {csv,xlsx,xml}` | формат вывода (по умолчанию `csv`) |
| `--unique` | оставить только последнюю копию каждой записи |
| `TABLE ...` | имена таблиц без расширения; по умолчанию — все |

Код возврата: `0` — успех, `1` — если какая-то таблица не выгрузилась.

## Замечания по выводу

- **Кодировка** — всё пишется в UTF-8, кириллица сохраняется независимо от
  исходной кодовой страницы файла.
- **Даты** в XLSX становятся настоящими датами Excel, время — настоящим
  временем, числовые колонки — числами; строки с ведущими нулями (индексы)
  намеренно остаются текстом.
- **Дубли ключей** — в некоторых реальных файлах одна и та же запись встречается
  дважды (обычно после аварийного завершения или ручного копирования базы).
  По умолчанию такие строки сохраняются и помечаются колонкой `_dup_key`; с
  `--unique` выгружается только более новая копия.
- **Заявлено vs фактически** — счётчик записей в заголовке Paradox может
  врать; инструмент экспортирует все непустые строки из цепочки блоков.

## Данные и приватность

В репозитории **только исходный код**. Файлы баз, дампы таблиц и всё, что из
них получено, **не включены** — вы сами указываете программе свои `.DB`.
`.gitignore` дополнительно блокирует `*.DB` и папки экспорта.
